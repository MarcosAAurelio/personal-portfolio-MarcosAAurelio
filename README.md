## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **portfólio pessoal interativo**. O projeto foi construído para apresentar minha trajetória profissional em suporte de TI, minha formação acadêmica em Engenharia de Software na **Universidade Católica de Brasília** e meus projetos práticos de programação.

Desenvolvido com **HTML5 semântico**, **CSS3 moderno** e **JavaScript Vanilla**, o site prioriza leveza, acessibilidade, alto desempenho e uma experiência visual refinada em qualquer dispositivo.

## ✨ Recursos e Diferenciais

- 🌐 **Suporte Bilíngue Completo (PT-BR / EN-US):** Tradução instantânea de toda a interface e projetos via JavaScript com persistência da preferência no `localStorage`.
- 🌓 **Temas Escuro e Claro:** Paleta de cores baseada em variáveis CSS (design tokens), com transições suaves e memorização de tema escolhido pelo usuário.
- 📱 **Design Totalmente Responsivo:** Layout adaptável para smartphones, tablets e desktops com menu de contatos colapsável (gaveta) em telas menores.
- ⚡ **Navegação SPA Fluida:** Troca entre seções (*Sobre*, *Experiência*, *Projetos*, *Contato*) com microanimações e suporte a histórico/hash de rotas (`#sobre`, `#experiencia`, `#projetos`, `#contato`).
- 🔍 **Visualizador de Foto Interativo:** Modal em tela cheia com fechamento por clique ou tecla `Esc`.
- 💬 **Contato Ágil:** Integração direta com WhatsApp (mensagem personalizada de acordo com o idioma selecionado) e botão de cópia de e-mail em um clique via Clipboard API.

## 💻 Como Executar o Projeto

Como o projeto é construído em tecnologias web puras (Vanilla JS), você não precisa de nenhuma dependência externa ou processo de build:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/MarcosAAurelio/personal-portfolio-MarcosAAurelio.git
   ```

2. **Acesse o diretório:**
   ```bash
   cd personal-portfolio-MarcosAAurelio
   ```

3. **Abra o arquivo `index.html`:**
   - Dê um duplo clique no arquivo `index.html` no seu navegador favorito; ou
   - Use uma extensão como o **Live Server** no VS Code / editor; ou
   - Inicie um servidor HTTP simples (ex: `npx serve .` ou `python -m http.server 3000`).
